# Ibarura — Static Starter E-commerce

This is a plain **HTML/CSS/JS** starter e-commerce project (client-side only).
It includes:
- index.html homepage with product grid
- client-side search using `assets/data/products.json`
- placeholder product images (SVG)
- Netlify `_redirects` for SPA routing

To deploy to Netlify:
1. Create a new site, connect to this repo.
2. Set **publish directory** to `/` (root).
3. Deploy.

To deploy to GitHub Pages:
1. Push to repo, enable Pages on `main` branch with root folder.

Files of interest:
- `index.html`
- `assets/css/style.css`
- `assets/js/main.js`
- `assets/data/products.json`
- `_redirects`
